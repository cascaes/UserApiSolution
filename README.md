# UserApiSolution
API REST em .NET. utilizando ASP.NET Core

rota de consulta no banco SqlLite acessível somente se autenticado

Clone o projeto:
git clone https://github.com/cascaes/UserApiSolution.git

Navegue até a pasta do projeto:
cd UserApiSolution/UserApi

Restaurar pacotes (se necessário):
dotnet restore

Executar o projeto:
dotnet run
